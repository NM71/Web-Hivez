CSS Overflow

The CSS overflow property controls what happens to content that is too large for its container. It can be set to one of the following values:

  • visible: The default value. Content that overflows the container will be visible.
  • hidden: Content that overflows the container will be hidden and not visible.
  • scroll: Content that overflows the container will be scrollable, allowing users to scroll through the content.
  • auto: If content overflows the container, scrollbars will appear as needed.
