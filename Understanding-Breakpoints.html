Bootstrap breakpoint names

  • xs <576px — uses col-* classes
  • sm ≥576px — use col-sm-*
  • md ≥768px — use col-md-*
  • lg ≥992px — use col-lg-*
  • xl ≥1200px — use col-xl-*
  • xxl ≥1400px — use col-xxl-*

In this example, each box is full width on extra small screens, half width on small screens, one third width on medium screens, and one quarter width on large screens.
